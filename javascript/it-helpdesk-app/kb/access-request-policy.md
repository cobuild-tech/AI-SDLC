# Access request policy

## Requesting access to a shared drive or system

1. Raise a ticket naming the shared drive, system or group you need, and why.
2. Your manager must approve the request in the ticket. Approval by email is not accepted, because it cannot be audited.
3. The identity team adds you to the group, usually within 1 working day of approval.

## Privileged groups

Some groups grant access to sensitive data or admin rights: domain-admins, security-admins and finance-prod. Access to these groups needs:

- manager approval in the ticket, and
- approval from the data owner (for finance-prod, the Finance Director) or from the security team for admin groups.

Privileged access is reviewed every 90 days and removed if no longer needed.

## Leaving or changing teams

When you change teams, access tied to your old team is removed after 30 days. Request any access you still need through a new ticket.

## Phishing and suspicious requests

IT will never ask for your password or MFA code. If you receive a message asking for them, do not reply. Report it as an urgent ticket. If you clicked a link or entered anything, say so in the ticket so the security team can reset your session.
