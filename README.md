# Agentic Coding across the SDLC: module code

This branch holds the code for every hands-on module, one folder per module. The step-by-step guides are on the [`main` branch](https://github.com/cobuild-tech/AI-SDLC/tree/main).

- **`demo-exercise` branch**: the starting code. This is where you work.
- **`solution` branch**: the same folders with the reference answers.

| Folder | Module |
|---|---|
| `module-1/` | 1. First supervised agent session |
| `module-3/` | 3. Context, memory and skills |
| `module-5-greenfield/` | 5. Greenfield |
| `module-5-brownfield/` | 5. Brownfield |
| `module-6/` | 6. Team operating model |
| `module-7/` | 7. Guardrails (review an agent's work) |
| `module-8/` | 8. Capstone |

On the `solution` branch, `module-5-greenfield-one-shot/` shows what a single "build everything" prompt produces, and `module-7/ANSWER-KEY.md` lists every problem planted in module 7.

Open one module folder at a time in VS Code, and start your coding agent in that folder.
